# 一起开饭：双人浏览器原型

这是一个独立于 Unity 场景的浏览器可玩原型，采用"房主权威 + PeerJS DataConnection"的轻量联机方式。房主创建 6 位房间码，朋友输入房间码加入；房主负责保存关卡进度并把状态广播给搭档。

## 玩法

- 创建房间 / 输入房间码加入；一间厨房支持两位玩家。
- 房主开始料理；五个步骤依次为备料、和面、包饺子、煮制、摆盘。
- 每个步骤需要两位玩家各贡献一次，合作进度分别推进到 50% 和完成；状态由房主同步给另一端。
- 完成后显示合作评分与用时；房主可发起再玩一局。

## 部署说明

本页面已部署到 GitHub Pages。PeerJS 库从 unpkg CDN 加载，字体已本地化回退，无需额外配置。
